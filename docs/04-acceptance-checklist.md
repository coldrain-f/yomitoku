# QAチェックリスト

機能追加後は、まず関連する自動検証を実行します。デプロイ前には、以下の主要フローを実際のブラウザで確認します。iPhone SafariとAndroid Chromeの両方を対象にします。

## 自動検証

```powershell
npm test
npm run build
docker compose run --rm --no-deps api sh -c "pip install '.[dev]' && ruff check app tests && pytest -q"
```

## 受講者の主要フロー

- [ ] ランディングでサービス説明を確認し、ログイン画面へ移動する。
- [ ] Googleログイン後に読解問題一覧へ移動し、ログアウト後にランディングへ戻る。
- [ ] 日本語・韓国語の切替、検索、フィルター、並び替え、ページネーションが連動して動作する。検索語をすばやく変えても、最後の検索条件の結果だけが残る。
- [ ] ブックマークの設定・解除とブックマークフィルターが、現在の言語の問題に正しく適用される。設定・解除は即時に表示され、トーストの取り消しで直前の状態を復元できる。
- [ ] 開始ダイアログにタイトル・レベル・種類・テーマが表示され、モバイルでタイトルが不自然に切れない。
- [ ] 新しい試行で選択肢がシャッフルされ、中・長文ではすべての設問に答えなければ提出できない。キーボードの方向キー、Home、Endで選択肢グループを移動・選択できる。
- [ ] 解答・結果画面を同じブラウザタブで再読み込みしても、現在の試行と提出結果が復元される。有効な現在の試行がない直接URLは、空白画面ではなく一覧へ移動する。
- [ ] 提出結果に、正答数、設問ごとの正誤、正答、解説、誤答解説、時間、正答率が正しく表示される。
- [ ] もう一度解くと新しい試行を作成し、100／90／80のスコアルールが一覧と結果で一貫して表示される。
- [ ] 正答後の次の問題が、現在の検索語・言語・レベル・種類・ブックマーク条件における未回答問題から選ばれる。対象がなければ、完了案内と一覧への復帰を表示する。

## モバイル・ハイライト

- [ ] iPhone SafariとAndroid Chromeで、本文をドラッグしてテキスト選択できる。
- [ ] 選択するとハイライトのフローティングボタンが有効になり、選択を解除すると無効になる。
- [ ] ハイライトとタイマーのフローティングボタンが、本文や提出ボタンを隠さない。
- [ ] ハイライトの作成・削除後、画面と一覧がすぐに一致する。
- [ ] ハイライト一覧の言語フィルター・検索・5件単位のページネーション・削除確認が動作する。
- [ ] 翻訳ダイアログに本文、設問、選択肢が一貫した順序で表示される。

## 管理者の主要フロー

- [ ] 手動登録と編集で、複数の設問・選択肢・正答・解説を保存できる。
- [ ] 手動登録・編集の目安時間は、`1分`、`1分30秒`、`2分`などの読みやすい選択肢で入力され、既存の例外値も保持される。
- [ ] AIによるタイトル・テーマ・解説の提案が、編集と手動登録で動作する。
- [ ] 編集を保存すると、一覧・詳細の値と更新日が更新される。
- [ ] 管理者の編集・プレビューURLを新しいタブで開いても、詳細が読み込まれる。すべての設問・選択肢・解説・目安時間の変更は離脱確認の対象であり、変更がなければ確認なしで移動する。
- [ ] 本文変更時にハイライト削除の警告が表示され、キャンセルするとデータが保持される。
- [ ] 公開・保留・保留解除・削除が状態ルールどおりに動作し、受講者への表示も正しい。
- [ ] 生成リクエスト中に再読み込み・重複クリックしても、実行中タスクが再利用され、履歴・エラー・利用量を確認できる。

## 多言語・アクセシビリティ

- [ ] 日本語・韓国語へ切り替えた後も、タイトル原文のフォント、レベル表記、フィルター、エラーメッセージが一貫して表示される。
- [ ] アイコンボタンにラベル・ツールチップがあり、キーボードで操作できる。
- [ ] ダイアログは開いたときに内部へフォーカスを置き、Esc、背景クリック、Tabによるフォーカス循環、モバイルでのスクロールロックに対応し、閉じると実行ボタンにフォーカスを戻す。

## 不具合記録

発見した問題は、次の形式で記録します。

```text
環境: デバイス / OS / ブラウザ / 画面サイズ
アカウント: 受講者 または 管理者
再現手順: 1. ... 2. ... 3. ...
期待結果:
実際の結果:
スクリーンショット または 動画:
```

再現可能な不具合は、原因を修正した後に該当レイヤーの回帰テストを追加します。見た目や操作の問題には、このチェックリストに事例を追加して再発を防ぎます。
