# QA 체크리스트

기능 추가 뒤에는 관련 자동 검증을 먼저 실행하고, 배포 전에는 아래 핵심 흐름을 실제 브라우저에서 확인한다. iPhone Safari와 Android Chrome을 모두 포함한다.

## 자동 검증

```powershell
npm test
npm run build
docker compose run --rm --no-deps api sh -c "pip install '.[dev]' && ruff check app tests && pytest -q"
```

## 학습자 핵심 흐름

- [ ] 랜딩에서 서비스 설명을 확인하고 로그인 화면으로 이동한다.
- [ ] Google 로그인 뒤 독해 목록으로 이동하고, 로그아웃 뒤 랜딩으로 돌아간다.
- [ ] 일본어·한국어 전환, 검색, 필터, 정렬, 페이지네이션이 함께 동작한다. 검색어를 빠르게 바꿔도 마지막 검색 조건의 결과만 남는다.
- [ ] 북마크 설정·해제와 북마크 필터가 현재 언어 문항에 정확히 적용된다. 설정·해제는 즉시 보이고 토스트의 되돌리기로 직전 상태를 복구할 수 있다.
- [ ] 시작 다이얼로그에 제목·등급·유형·주제가 표시되고, 모바일 제목이 잘리지 않는다.
- [ ] 새 시도에서 선택지가 섞이고, 중·장문에서는 모든 질문에 답해야 제출된다. 키보드 방향키·Home·End로 선택지 그룹을 이동·선택할 수 있다.
- [ ] 풀이·결과 화면을 같은 브라우저 탭에서 새로고침해도 현재 시도와 제출 결과가 복원된다. 유효한 현재 시도가 없는 직접 URL은 빈 화면이 아닌 목록으로 이동한다.
- [ ] 제출 결과에 맞힌 문항 수, 문제별 정오답, 정답, 해설, 오답 해설, 시간, 정답률이 맞게 표시된다.
- [ ] 다시 풀기는 새 시도를 만들며 100/90/80 점수 규칙이 목록과 결과에 일관되게 보인다.
- [ ] 정답 뒤 다음 문항은 현재 검색어·언어·등급·유형·북마크 조건의 미풀이 문항에서 선택된다. 대상이 없으면 완료 안내와 목록 복귀를 보여 준다.

## 모바일·하이라이트

- [ ] iPhone Safari와 Android Chrome에서 지문 드래그로 텍스트 선택이 가능하다.
- [ ] 선택하면 하이라이트 플로팅 버튼이 활성화되고, 선택을 해제하면 비활성화된다.
- [ ] 하이라이트와 시간 플로팅 버튼이 본문·제출 버튼을 가리지 않는다.
- [ ] 하이라이트 생성·삭제 후 즉시 화면과 모아 보기 목록이 일치한다.
- [ ] 하이라이트 모아 보기의 언어 필터·검색·5개 단위 페이지네이션·삭제 확인이 동작한다.
- [ ] 번역 다이얼로그에 지문, 질문, 선택지가 일관된 순서로 표시된다.

## 관리자 핵심 흐름

- [ ] 수동 등록과 편집에서 복수 질문·선택지·정답·해설을 저장할 수 있다.
- [ ] 수동 등록과 편집의 권장 시간은 `1분`, `1분 30초`, `2분` 등 읽기 쉬운 선택지로 입력되며 기존 예외 값도 보존된다.
- [ ] AI 제목·주제·해설 제안이 편집과 수동 등록에서 동작한다.
- [ ] 편집 저장 뒤 목록·상세의 값과 수정일이 갱신된다.
- [ ] 관리자 편집·미리보기 URL을 새 탭에서 열어도 상세가 로드된다. 모든 질문·선택지·해설·권장 시간의 변경은 이탈 확인 대상이고, 변경이 없으면 확인 없이 이동한다.
- [ ] 지문 변경 시 하이라이트 삭제 경고가 표시되고, 취소하면 데이터가 유지된다.
- [ ] 게시·보류·보류 해제·삭제가 상태 규칙대로 작동하고 학습자 노출도 맞다.
- [ ] 생성 요청 중 새로고침·중복 클릭 뒤에도 활성 작업을 재사용하고 이력·오류·사용량을 확인할 수 있다.

## 다국어·접근성

- [ ] 한국어·일본어 전환 뒤 제목 원문 폰트, 등급 표기, 필터, 오류 메시지가 일관되게 보인다.
- [ ] 아이콘 버튼에는 레이블·툴팁이 있고 키보드로 조작 가능하다.
- [ ] 다이얼로그는 열릴 때 내부에 포커스를 두고, Esc·배경 클릭·Tab 포커스 순환·모바일 스크롤 잠금을 지원하며 닫으면 실행 버튼으로 포커스를 돌려준다.

## 결함 기록

발견한 문제는 다음 형식으로 남긴다.

```text
환경: 기기 / OS / 브라우저 / 화면 크기
계정: 학습자 또는 관리자
재현 절차: 1. ... 2. ... 3. ...
기대 결과:
실제 결과:
스크린샷 또는 동영상:
```

재현 가능한 오류는 원인 수정 뒤 해당 계층의 회귀 테스트를 추가한다. 시각·조작 문제는 이 체크리스트에 사례를 추가해 재발을 막는다.
