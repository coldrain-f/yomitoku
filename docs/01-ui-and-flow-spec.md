# 화면 및 사용자 흐름 명세

## 공통 원칙

- 첫 화면은 서비스 소개 랜딩이다. 독해 목록은 로그인 후에만 연다.
- Google 로그인 성공 뒤 서버 토큰과 역할을 확인한다. 학습자와 관리자의 노출 차이는 편의 UI이며, 권한 판단은 서버가 한다.
- UI 언어는 한국어와 일본어를 지원한다. 문항 원문 폰트와 내용은 UI 언어 전환과 독립적으로 유지한다.
- 서버 요청 중에는 목록 영역 중앙의 스피너를 사용한다. 화면 전체를 불필요하게 가리는 박스·문구는 사용하지 않는다. 화면 단위 코드는 필요할 때 불러와 초기 진입량을 줄인다.
- 목록 검색은 입력이 300ms 동안 멈춘 뒤 요청하며, 새 검색·필터 요청이 시작되면 이전 요청은 취소한다. 모든 프런트엔드 API 요청은 15초 안에 끝나지 않으면 실패로 처리한다.
- 파괴적 동작(문항 삭제, 하이라이트 삭제, 지문 변경으로 인한 하이라이트 삭제)은 확인 다이얼로그를 거친다. 북마크는 즉시 저장하고 짧은 시간 동안 되돌리기를 제공한다.

## 학습자 흐름

### 랜딩과 로그인

1. 랜딩은 서비스 목적, 독해 미리보기, 결과·북마크·하이라이트 기능을 보여 준다.
2. 기본 CTA와 보조 CTA는 모두 로그인 화면으로 이동한다.
3. 로그인 화면에서는 Google 계정을 사용하고, 돌아가기는 랜딩으로 이동한다.
4. 로그인 뒤에는 독해 목록으로 이동한다. 로그아웃하면 랜딩으로 돌아간다.

### 독해 목록

- 일본어·한국어 탭으로 언어를 바꾼다.
- 검색, 등급, 유형, 주제, 풀이 상태, 첫 제출 시간, 정렬, 페이지네이션을 제공한다.
- 검색 중에는 이전 결과가 늦게 도착해 최신 검색·필터 결과를 덮어쓰지 않아야 한다.
- 로그인 사용자에게 북마크 토글과 북마크 목록 필터를 제공한다. 북마크는 현재 선택한 언어의 문항에 적용된다.
- 아이콘 전용 북마크·필터·하이라이트 모아 보기 버튼은 우측에 정렬하고 접근성 레이블을 가진다.
- 행에는 제목, 등급, 단/중/장문, 주제, 풀이 상태, 점수, 날짜를 표시한다. 날짜는 `YY.MM.DD` 형식으로 표시한다.
- 시작 다이얼로그에는 제목과 등급·유형·주제 메타 정보를 함께 표시한다. 제목은 모바일에서 말줄임표 처리한다.

### 풀이와 결과

- 서버가 매 시도마다 선택지 순서를 섞고, 제출에는 화면 번호가 아닌 선택지 ID를 사용한다.
- 단문은 1문항, 중문은 최대 3문항, 장문은 최대 4문항을 가질 수 있다.
- 타이머는 우측 하단 플로팅 버튼으로 확인할 수 있다. 제출 전에는 모든 문제의 답을 골라야 한다.
- 선택지는 `radio` 그룹으로 동작한다. Tab으로 그룹에 진입하고 방향키, Home, End로 같은 질문의 선택지를 이동·선택할 수 있다.
- 본문에서 선택한 텍스트는 하이라이트 버튼으로 저장한다. 모바일에서는 하이라이트 조작 버튼을 우측 하단에 고정한다. 선택이 사라지면 버튼도 비활성 상태로 돌아간다.
- 제출 결과는 맞힌 문항 수를 주정보로 두고, 문제별 정오답, 선택한 답, 정답, 해설, 오답 해설, 권장/실제 시간, 정답률을 표시한다. 오답이면 다시 풀기는 새 시도를 만든다.
- 정답 뒤 다음 문항은 현재 검색어·언어·등급·유형·북마크 조건 전체에서 아직 풀지 않은 문항을 찾는다. 없으면 현재 조건 완료를 알리고 목록으로 돌아갈 수 있게 한다.
- 풀이 또는 결과 URL을 같은 브라우저 탭에서 새로고침하면 저장된 현재 시도를 서버에서 다시 조회해 복원한다. 저장된 시도가 없거나 다른 사용자의 URL이면 목록으로 안전하게 이동하며, URL만으로 학습 시도를 다른 사용자에게 공유하지 않는다.
- 번역 보기는 다이얼로그에서 원문과 번역, 질문과 선택지를 함께 보여 준다.

### 개인 학습 기록

- 하이라이트 모아 보기는 다이얼로그에서 전체·일본어·한국어 필터, 검색, 5개 단위 페이지네이션을 제공한다.
- 하이라이트 삭제는 확인 뒤 실행한다. 삭제 확인 다이얼로그를 열어도 원래 모아 보기 다이얼로그의 문맥을 유지한다.
- 통계는 완료 수, 정답률, 평균 시간과 언어·유형·등급별 집계를 제공한다.

## 관리자 흐름

- 관리자만 문항 목록, 수동 등록, AI 생성, 생성 이력에 접근한다.
- 목록은 검색·필터·정렬·페이지네이션을 제공하고, 필터 아이콘은 목록 우측 끝에 둔다.
- 수동 등록과 편집은 복수 문항을 지원한다. 첫 문항의 삭제 버튼은 보이되 비활성화해 UI 구조를 일관되게 유지한다.
- 수동 등록과 편집의 권장 시간은 초 단위 자유 입력 대신 `1분`, `1분 30초`, `2분` 등 사전 정의된 선택지로 입력한다. 기존 데이터의 예외 값은 현재 값도 선택지에 남긴다.
- 제목·주제·해설 AI 제안은 수동 등록과 편집 모두에서 사용할 수 있다.
- 편집·미리보기 URL을 직접 열면 항목 상세를 조회한 뒤 표시한다. 임시 초안은 제목·지문·권장 시간·모든 질문·선택지·해설이 바뀐 경우에만 이탈 확인을 표시한다.
- 지문을 바꿀 때 학습자의 하이라이트가 존재하면, 모든 사용자의 해당 하이라이트가 삭제된다는 경고와 확인을 보여 준다.
- 문항은 `review`, `held`, `published` 상태를 사용한다. 학습자에게는 `published`만 보인다.

## 반응형·접근성

- 모바일에서 목록 제목은 한 줄 말줄임표, 메타 정보와 버튼은 명확한 줄바꿈을 사용한다.
- 다이얼로그는 배경 스크롤을 잠그고, 열릴 때 첫 조작 요소에 포커스를 옮긴다. 닫기·취소·Esc·배경 클릭·Tab 포커스 순환을 지원하며, 닫으면 실행 버튼으로 포커스를 되돌린다.
- 아이콘 버튼에는 `aria-label`과 툴팁을 제공한다. 정오답·상태는 색상만으로 전달하지 않는다.
