# UI・ユーザーフロー仕様

## 共通原則

- 最初に表示する画面はサービス紹介のランディングです。読解問題一覧はログイン後にのみ開きます。
- Googleログインの成功後、サーバートークンとロールを確認します。受講者と管理者の表示差は利便性のためのUIであり、権限判定はサーバーが担います。
- UIは日本語と韓国語に対応します。問題の原文フォントと内容は、UI言語の切替とは独立して維持します。
- サーバーリクエスト中は、一覧領域の中央にスピナーを表示します。画面全体を不要に覆うボックスや文言は使用しません。画面単位のコードは必要になったときに読み込み、初期ロード量を減らします。
- 一覧検索は入力が300ms止まってからリクエストし、新しい検索・フィルターリクエストが始まったら前のリクエストをキャンセルします。すべてのフロントエンドAPIリクエストは、15秒以内に完了しない場合は失敗として扱います。
- 破壊的な操作（問題削除、ハイライト削除、本文変更に伴うハイライト削除）は確認ダイアログを経由します。ブックマークは即時保存し、短時間の取り消しを提供します。

## 受講者フロー

### ランディングとログイン

1. ランディングでは、サービスの目的、読解プレビュー、結果・ブックマーク・ハイライト機能を示します。
2. メインCTAと補助CTAはいずれもログイン画面へ移動します。
3. ログイン画面ではGoogleアカウントを使用し、戻る操作はランディングへ移動します。
4. ログイン後は読解問題一覧へ移動します。ログアウトするとランディングへ戻ります。

### 読解問題一覧

- 日本語・韓国語タブで言語を切り替えます。
- 検索、レベル、種類、テーマ、解答状態、初回提出日時、並び替え、ページネーションを提供します。
- 検索中は、遅れて届いた古い結果が最新の検索・フィルター結果を上書きしてはいけません。
- ログインユーザーにはブックマークの切替とブックマーク一覧フィルターを提供します。ブックマークは、現在選択している言語の問題に適用されます。
- アイコンのみのブックマーク、フィルター、ハイライト一覧ボタンは右側に配置し、アクセシビリティラベルを設定します。
- 行にはタイトル、レベル、短・中・長文、テーマ、解答状態、スコア、日付を表示します。日付は`YY.MM.DD`形式で表示します。
- 開始ダイアログには、タイトルとレベル・種類・テーマのメタ情報を一緒に表示します。モバイルではタイトルを省略記号で切り詰めます。

### 解答と結果

- サーバーは試行ごとに選択肢の順番をシャッフルし、提出には画面上の番号ではなく選択肢IDを使用します。
- 短文は1設問、中文は最大3設問、長文は最大4設問を持てます。
- タイマーは右下のフローティングボタンで確認できます。提出前にはすべての設問を選択する必要があります。
- 選択肢は`radio`グループとして動作します。Tabでグループに入り、方向キー、Home、Endで同じ設問の選択肢を移動・選択できます。
- 本文で選択したテキストはハイライトボタンで保存します。モバイルではハイライト操作ボタンを右下に固定します。選択が消えるとボタンも無効状態に戻ります。
- 提出結果では正答数を主情報とし、設問ごとの正誤、選択した解答、正答、解説、誤答解説、目安時間・実際の時間、正答率を表示します。不正解の場合、もう一度解くと新しい試行を作成します。
- 正答後の次の問題は、現在の検索語、言語、レベル、種類、ブックマーク条件全体から未回答の問題を探します。なければ、現在の条件を完了したことを知らせ、一覧へ戻れるようにします。
- 解答・結果URLを同じブラウザタブで再読み込みした場合、保存済みの現在の試行をサーバーから再取得して復元します。保存済みの試行がない、または別ユーザーのURLでは安全に一覧へ移動し、URLだけで試行を他ユーザーと共有しません。
- 翻訳表示はダイアログで原文と翻訳、設問と選択肢を一緒に表示します。

### 個人学習記録

- ハイライト一覧はダイアログで全体・日本語・韓国語フィルター、検索、5件単位のページネーションを提供します。
- ハイライトの削除は確認後に実行します。削除確認ダイアログを開いても、元の一覧ダイアログの文脈を保ちます。
- 統計では、完了数、正答率、平均時間、言語・種類・レベル別の集計を提供します。

## 管理者フロー

- 管理者だけが問題一覧、手動登録、AI生成、生成履歴にアクセスできます。
- 一覧は検索、フィルター、並び替え、ページネーションを提供し、フィルターアイコンは一覧の右端に置きます。
- 手動登録と編集は複数設問に対応します。最初の設問の削除ボタンは表示しますが、無効化してUI構造を一貫させます。
- 手動登録・編集の目安時間は、秒数の自由入力ではなく、`1分`、`1分30秒`、`2分`などの事前定義された選択肢で入力します。既存データにある例外値も現在の値として選択肢に残します。
- タイトル、テーマ、解説のAI提案は、手動登録と編集の両方で使用できます。
- 編集・プレビューURLを直接開いた場合、項目の詳細を取得してから表示します。一時下書きでは、タイトル、本文、目安時間、すべての設問・選択肢・解説が変更された場合のみ離脱確認を表示します。
- 本文を変更するとき、受講者のハイライトが存在する場合は、全ユーザーの該当ハイライトが削除されることを警告・確認します。
- 問題の状態は`review`、`held`、`published`を使用します。受講者に見せるのは`published`のみです。

## レスポンシブ対応・アクセシビリティ

- モバイルでは一覧タイトルを1行の省略記号にし、メタ情報とボタンは明確に改行します。
- ダイアログは背景スクロールをロックし、開いたときに最初の操作要素へフォーカスを移します。閉じる、キャンセル、Esc、背景クリック、Tabによるフォーカス循環に対応し、閉じたときは実行ボタンへフォーカスを戻します。
- アイコンボタンには`aria-label`とツールチップを提供します。正誤・状態を色だけで伝えません。
- 実際のQAは[04-acceptance-checklist.md](./04-acceptance-checklist.md)に従います。
